# Changelog

## 0.2.0

- Build and test GIF search, image loading and seat management against the published Stellarr SDK 0.4.

- Named Gif Me a Break (working name Pętla), with a new wordmark and cover.
- Polish and English, following each player's Stellarr language. Topics, awards and refusals are put into words on each player's screen, so one room can mix both languages.
- Four modes: Classic, Banned words, Director (a rotating player picks the topic and the winner, 3 points) and Captions (everyone writes a caption for the same GIF).
- The host can end a match early; the final screen shows the scores as they are.
- Backgrounds: a doodle pattern, a sofa in the lobby, a spotlight for the reveal, confetti for winners.

## 0.1.0

- First version: lobby with players from the voice channel, topic vote, GIF search through `media.gifs`, reveal with live stickers, vote, round results and the final screen with a podium and awards.
